# Guardian AI — Machine Learning Subsystem

## Overview
The ML subsystem is responsible for developing, training, and evaluating predictive risk models to support proactive threat awareness.

## Technology Stack
- **Languages**: Python 3.10+
- **Frameworks**: scikit-learn, XGBoost, NumPy, pandas
- **Geospatial Processing**: GeoPandas, Shapely

## Model Evaluation Guidelines
- Models must be evaluated using standard cross-validation and documented evaluation metrics (Precision, Recall, F1-Score, ROC-AUC).
- Machine learning accuracy percentages must NOT be claimed until empirically validated against held-out historical crime test sets.
- Integration scheduled for Phase 8.
