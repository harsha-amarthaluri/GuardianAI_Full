# Guardian AI — Admin Portal Subsystem

## Overview
The Admin portal provides system administrators and safety operators with tools to:
- Monitor active SOS emergency incidents in real-time.
- Import and review historical crime datasets.
- Manage user privileges and guardian network verifications.
- Review system health and audit logs.

## Architecture
- Planned to interface with `/api/v1/admin/*` FastAPI backend endpoints.
- Integration scheduled for Phase 7.
